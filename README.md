# PDFs Editors — Free Online PDF Tools

PDFs Editors is a web-based project that provides simple, free tools to manage and edit PDF files directly through a web browser. It is designed to make common PDF tasks easy, fast, and accessible without requiring users to install additional software.

### Features
- **Merge PDF:** Combine multiple PDF files into one.
- **Split PDF:** Separate PDF pages into individual files.
- **Rotate PDF:** Rotate pages to the correct orientation.
- **JPG/PNG to PDF:** Convert images into PDF documents.
- **Organize PDF:** Rearrange PDF pages.
- **Add Page Numbers:** Insert page numbers into documents.
- **Watermark PDF:** Add watermarks to PDF files.
- **Text to PDF:** Create PDF documents from text.

### Technologies Used
HTML, CSS, JavaScript, and browser-based PDF processing libraries.

### Project Goal
To provide an easy-to-use, free online PDF editing platform that helps users manage their documents conveniently.
